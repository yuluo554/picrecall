| **2026-10-16** | **D-18 默认 profile 保持 `char`；`simple` 为可选主路径** | 实测同一 60 图集：char 检索命中率 0.9375（达标）、simple 0.8438（未达标，根因是真值查询截断切在词中间与词级粒度错配）；**不为让主路径达标而改已入仓真值** |
| **2026-10-16** | **D-19 近似重复样例只用"缩放 + 编码差异"构造** | 实测 pHash **不抗平移**（平移 2px 距离即 26 ≫ 阈值 8），故原提议的"轻微位移"被实测否决；亮度虽有可落阈值内但正/反向极端亮度间擦边 8–10 无余量。定案：族内 = PNG 1.00 / PNG 1.15 / BMP 0.95（60 族实测族内 6、族间 56） |
| **2026-10-16** | **D-20 `apply_scan` 必须写入 width/height（修复 K11 分辨率级端到端失效）** | 实测索引后 60/60 的 width/height 为 NULL，致 K11 第①级（分辨率）端到端**恒不生效**、退化成只比文件大小；而单元测试（手工构造 members）全绿，缺口长期隐形。新增 `index.read_dimensions()`（宽容失败）+ 构造锁 + 变异验证 |
